# Evidências de contexto e riscos

Guardar versões aprovadas de:

- matriz de ao menos quatro partes interessadas;
- descrição do contexto de uso;
- inventário de dados e fontes;
- regras de supervisão humana;
- riscos, danos, erros aceitáveis e inaceitáveis;
- registro da reunião que aprovou o recorte.

Cada documento deve informar data, autores e revisores.
